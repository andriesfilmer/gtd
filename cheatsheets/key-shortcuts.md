# Common Keyboard Shortcuts Reference

> Focus: shortcuts involving Ctrl, Alt, Shift, Super, Menu, Fn and combinations.
>
> "Common" means widely used across Linux, Windows, macOS, browsers, terminals,
> editors and desktop applications. Application-specific shortcuts are marked.

## Legend

- 🟢 Very common — avoid remapping
- 🟡 Common in some environments — use caution
- ⚪ Relatively uncommon — potentially good for remapping
- 🔴 System/desktop function — avoid remapping

---

# AltGr / Right Alt

AltGr is particularly important on international keyboards.

| Shortcut | Function | Frequency |
|---|---|---|
| `AltGr+E` | `€` on many layouts | 🟢 |
| `AltGr+2` | `²` / `@` depending on layout | 🟢 |
| `AltGr+3` | `³` / `#` depending on layout | 🟢 |
| `AltGr+4` | Currency/symbol | 🟢 |
| `AltGr+Q` | `@` on some layouts | 🟢 |
| `AltGr+M` | Special character on many layouts | 🟡 |
| `AltGr+<letter>` | Layout-dependent characters | 🟢 |

**Recommendation:** Never assume AltGr combinations are free. Check the active keyboard layout.

# Right Ctrl

Right Ctrl normally behaves exactly like Left Ctrl.

| Shortcut | Typical function | Frequency |
|---|---|---|
| `RightCtrl+C` | Copy / terminal interrupt | 🟢 |
| `RightCtrl+V` | Paste | 🟢 |
| `RightCtrl+X` | Cut | 🟢 |
| `RightCtrl+Z` | Undo | 🟢 |
| `RightCtrl+A` | Select all | 🟢 |
| `RightCtrl+S` | Save | 🟢 |
| `RightCtrl+F` | Find | 🟢 |
| `RightCtrl+W` | Close tab | 🟢 |
| `RightCtrl+T` | New tab | 🟢 |
| `RightCtrl+Tab` | Next tab | 🟢 |

**However:** Right Ctrl is often physically unused by users and can be a good keyd layer key if you don't need it for a keyboard layout.
